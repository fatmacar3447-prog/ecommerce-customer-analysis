# E-Commerce Customer Churn Analysis

## Proje Hakkında
50.000 müşteri verisini Python ile analiz ederek müşteri kaybının (churn) nedenlerini araştırdım.

## Kullanılan Araçlar
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab
- Dataset: 50.000 müşteri, 25 değişken

## Ana Bulgular
- Müşteri kayıp oranı: %28.9
- Ayrılan müşteriler daha yüksek harcama yapıyor (135 vs 118)
- Ayrılan müşterilerde sepet terk oranı çok daha yüksek (%64 vs %54)
- En güçlü gösterge: login sıklığı (Kalan: 12.6x, Ayrılan: 9.1x)

## Stratejik Öneriler
1. Login sıklığı düşen müşterilere otomatik bildirim gönder
2. Yüksek sepet terk oranlı müşterilere indirim teklif et
3. Yüksek harcayan ama ayrılan segmente VIP program oluştur
